# 唤醒词白名单（astrbot_plugin_wake_list）

只允许 AstrBot 管理员使用唤醒词（默认 `/`）唤醒机器人。

## 行为

- 非管理员发送 `/指令`：指令不执行（在指令 handler 之前拦截）。
- 非管理员发送 `/普通文字`：LLM 不回复（在 LLM 请求前拦截）。
- 消息默认仍会进入群聊上下文记录与历史库，之后 @ 机器人时它仍能理解刚才那句话；可在配置最下方关闭「被屏蔽的唤醒词/句是否加入上下文」。
- @ 机器人、引用机器人：不受影响，任何用户都可以。
- 管理员：始终豁免。
- 插件页的启用/禁用总开关关闭时，本插件完全不生效；配置保留。

## 名单格式

一行一条，和 AstrBot 核心白名单一致：

```
napcat_qq:GroupMessage:<群号>     # 群条目：作用于该群
napcat_qq:FriendMessage:<QQ号>    # 用户条目：作用于该用户的私聊，以及他在群里的发言
```

空行和以 `#` 开头的行会被忽略。

## 模式

「当前模式」下拉框有四个选项：

### 黑名单（blacklist）

名单内的群或用户被限制，其余放行。名单为空 = 不限制任何会话（等同关闭）。

### 白名单（whitelist）

名单内的群或用户放行，其余限制。名单为空 = 限制所有会话。

### 复杂模式-黑名单（complex_black）

- 群号层：**黑名单优先**。群号白名单失效；黑名单里的群被限制，黑名单外的群放行。
- Q 号层：**白名单优先**。用户白名单优先于黑名单；白名单用户即使所在群被拉黑，仍可正常使用唤醒词。

### 复杂模式-白名单（complex_white）

与上一条相反：

- 群号层：**白名单优先**。群号黑名单失效；白名单里的群放行，白名单外的群限制。
- Q 号层：**黑名单优先**。用户黑名单优先于白名单；黑名单用户即使在白名单群里，也会被限制。

## 上下文开关

配置最下方有「被屏蔽的唤醒词/句是否加入上下文」，默认开启：

- 开启：被拦截的 `/文字` 仍会进入群聊上下文，之后 @ 机器人时模型能看到它。
- 关闭：被拦截的 `/文字` 直接丢弃，不进入群聊上下文（消息仍会写入平台历史库，供历史查询工具使用）。

## 决策顺序

1. 管理员？→ 放行。
2. 消息不以唤醒词开头？→ 放行。
3. 按当前模式判断会话/用户是否受限：受限 → 拦截；否则放行。

## 说明

- 管理员来自 AstrBot 官方配置「访问控制 → 管理员 → 管理员 ID」（`admins_id`），插件内不保存任何账号。
- 需要 AstrBot >= 4.24.1。
